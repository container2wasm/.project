# Security Policy

## Reporting Security Issues

The container2wasm maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/container2wasm/container2wasm/security/advisories/new) form.

For more details, see the [container2wasm security policy](https://github.com/container2wasm/container2wasm/blob/main/SECURITY.md).
